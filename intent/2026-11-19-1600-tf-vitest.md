# Intent: Run a vitest subpackage with its own runner

## Problem

aifactory-demo #623 has ts/daterange/ with its own package.json and vitest. TFactory generated vitest tests but ran them under root jest with no npm install: 'Cannot find module vitest', 4/4 suites failed to load, triaged_empty, 6.34 USD.

## Proposed outcome

The unit lane resolves the nearest package.json to the test path; when it declares vitest, the lane installs that package's deps and runs vitest there. A failed install is a loud setup failure (exit 127, __JEST_SETUP_FAILED), not a test verdict.

## Affected users and systems

TFactory backend (apps/backend/agents), framework descriptors.

## Constraints

Narrow diff; other teams touch TFactory in parallel. No secrets, no live-cluster changes.

## Open questions

None. Decision (owner delegation 2026-11-19): take the fix recommended in the issue.
