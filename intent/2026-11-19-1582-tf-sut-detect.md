# Intent: Sidecars and self-served SUT for contract-less api specs

## Problem

factory-lab-cloud PR #1 (FastAPI+Postgres+Redis) failed 7/8 api tests with KeyError TFACTORY_TARGET_URL on 0.13.0. detect_serve_command and required_services both work on that repo's real layout (app/main.py, app/requirements.txt). The cause is routing: an ingested spec has no contract `environment` and the repo has no flake, so has_nix_env is false, the lane takes the host runner, and the sidecars and in-Job SUT of #1606 (which live only in the nix Job) never run.

## Proposed outcome

An api-lane subtask whose repo needs postgres/redis runs in the nix Job with sidecars, DATABASE_URL/REDIS_URL and the started SUT, even with no contract env.

## Affected users and systems

TFactory verify pipeline (web-server routes and backend agents); callers: cockpit, MCP proxy, spec-ingest verify runs.

## Constraints

Smallest correct change; tests that fail without the fix; no live-cluster action; repo-owned flakes and contracts keep winning.

## Open questions

None. Decided under the owner delegation of 2026-11-19 (recommended option).
