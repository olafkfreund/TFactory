# Intent: fix the TFactory findings from the 2026-11-23 UI test

## Problem

The browser test of prod (Factory#3873, TFactory#1660) found:

- 403 for the owner on `GET /api/projects/{id}/env` (MCP view, Project
  General).
- Opening a project shows an empty page, and "Tests" drops the project
  scope by jumping to `/tests`.
- Projects carry no slug and have path-derived names
  ("olafkfreund-aifactory-demo").
- Failed runs sit in the active Plan and Generate columns with no way to
  clear them.
- Settings shows "1.0.0-web".
- Add Project opens on a local folder.
- Recent Projects shows pod paths.

## Proposed outcome

- A project opens on its own test pipeline, and every nav item keeps the
  project.
- Projects show the repo name and slug.
- Failed runs leave the active columns: there is a "Failed (N)" filter, and
  the latest failure on a card offers Retry and Dismiss.
- The owner sees their settings with no 403, and the version is correct.

## Affected users and systems

TFactory web server and frontend.

## Constraints

- Secrets are never returned to non-admins.
- D6 holds.
- Dismiss reuses the existing review-gate route (`tfactory_tasks.py`
  `dismiss_run`).
- Bug fixes only.

## Open questions

None.
