# Intent: WebSockets work for SSO users

## Problem
The Logs tab, and the agent console, never connect for SSO users. WebSocket auth only reads a header or `?token=`. Browsers can't send the header, and SSO users only have the HttpOnly `access_token` cookie.

## Proposed outcome
The log stream and the agent console connect for SSO users. An unauthorised socket shows an error instead of spinning.

## Affected
The TFactory web server's WebSocket auth and the log viewer UI.

## Constraints
- No cross-site WebSocket hijacking: cookie auth only for same-origin handshakes.
- Header and `?token=` keep working.

## Open questions
None.
