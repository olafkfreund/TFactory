# Spec: Go generated tests must not collide with existing tests

## Design

In _stage_go_test (apps/backend/agents/evaluator.py): skip entries that are not relative *_test.go paths inside the project; never overwrite a differing existing file; collect top-level identifiers of the package's other .go files and, on collision, write a *_tfgen_test.go copy with colliding names renamed (Test -> TestTFGen...). Rename-instead-of-reject keeps the lane producing evidence without another model round.

## Alternatives rejected

Reject and regenerate with the collision list: costs another model round and the same collision can recur. Classing package compile failure as infra: lives in verdict-rule code owned by tf-sandbox, out of scope; with renaming the collision no longer occurs.

## Risks

Regex identifier scan misses grouped var/const members (documented shortcut).

## Verification

tests/test_evaluator_go_lane.py collision and no-overwrite tests.
