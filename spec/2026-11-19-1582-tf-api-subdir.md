# Spec: api lane resolves the python app nearest the spec targets

## Design

1. `detect_serve_command`: new `_python_subdir_serve(pd, targets, port)`, tried after the node
   subdir probe. For each target, walk its ancestor directories (deepest first, plain names
   only); the first dir holding `app/main.py` (exposing `app`) yields
   `python -m uvicorn --app-dir <dir> app.main:app --host 127.0.0.1 --port <port>`.
   Only the package layout is recognised (a bare `main.py` would make target
   `services/notes-api/app/main.py` pick `app/` itself as the import root; Codex P1). Targets at the repo root are not
   touched, so single-app repos behave as before.
2. The api lane passes the spec targets (`_api_targets`: source.json `target_paths`, else python paths named in the spec text; Codex P2)
   to `detect_serve_command` in `api_services_fallback_env`, `_resolve_serve` and the
   evaluator call site.
3. `materialize_flake(..., regenerate_generated=True)` (set by `run_pytest_lane_via_nix` when it
   has a fallback env): a repo-owned flake whose text carries the provisioner's
   "GENERATED by RFC-0005 nix_provisioner" marker is replaced, in the scratch copy, by the
   fallback flake (pytest, pytest-cov, requests, fastapi, uvicorn, httpx, pip when any
   requirements.txt exists). Requirements of the subdir are already pip-installed by
   `requirements_files`.

## Alternatives rejected

- Always override a repo flake in the api lane: breaks hand-written flakes.
- Patch `requests` in via pip at run time: pip is not in the committed flake.
- Edit the repo flake via PR: not our checkout to change.

## Risks

A marker-generated flake loses its node/playwright packages in the api lane only; the browser
lane does not pass `regenerate_generated`. Wrong subdir pick if a target is under a dir with
`app/main.py` that is not the SUT: readiness accepts any HTTP answer, so the marker would not catch it (Codex P2); tests assert which module is served.

## Verification

Unit tests with the aifactory-demo layout: serve command, targets plumbing, regenerated flake
carries requests, hand-written flake untouched, browser lane unaffected. Plus ratchet lint.
