# Spec: Enable the new models in TFactory

## Design

- `apps/backend/phase_config.py` MODEL_ID_MAP: opus -> claude-opus-5-5, sonnet -> claude-sonnet-5-5 (backend map was already claude-sonnet-5; frontend label said 4.6), haiku -> claude-haiku-5-5, add fable -> claude-fable-5-2. Legacy pinnable aliases: opus-4.8, sonnet-5, sonnet-4.6, haiku-4.5 (existing opus-4.7, opus-1m, opus-4.5 stay).
- `thinking_config_for`: a separate `_ADAPTIVE_ONLY` set (not the 4.7/4.8 set, so the interleaved beta is not extended); the 5.x ids always get `{"type":"adaptive"}` when level != none and ignore an explicit budget (budget_tokens is a 400 there). Interleaved beta stays 4.7/4.8 only. Known edge: level `none` returns None and the client then forwards any legacy budget; thinking cannot be disabled on Opus 5.5 so the 'none' level is not offered for it by the pickers' defaults.
- Frontend `models.ts`: AVAILABLE_MODELS, ALL_AVAILABLE_MODELS, PROVIDER_MODELS, MODEL_ID_MAP list new models first (Claude + gpt-6.x + gemini-4-*/3.8-flash-*), old ones kept below. Same lists in the Insights provider modules.
- `usage.py` price table: claude-opus-5-5 $4/$20, sonnet-5-5 $2/$10, haiku-5-5 $0.10/$0.50 (<=100K prompts; the estimator has one rate per prefix, so >100K prompts are under-estimated; shortcut noted in code), fable-5-2 $8/$40 (claude-api reference). No OpenAI/Gemini prices.
- `core/cache.py` min-cache floors for the new ids use the 4096 conservative floor.
- gen_functional shorthand set gains `fable`; provider inference already routes gpt-*/gemini*.
- Insights Claude list keeps CLI shorthands opus/sonnet/haiku (the CLI resolves them) plus the full id claude-fable-5-2; backend-only aliases are not offered there.
- The Gemini guard test regex is widened to 3.8 and gemini-4 ids.
- Gemini ids use only variants seen in the local agy config: gemini-4-{carbon,argon,neon}-medium, gemini-3.8-flash-{high,low}.
- Codex list from ~/.codex/models_cache.json: gpt-6.2-sol, gpt-6.2-astra, gpt-6.1-terra, gpt-6.1-sol, gpt-6-astra, gpt-6-sol, gpt-6-luna, gpt-5.6-sol/terra/luna.

## Alternatives rejected

- Dated/unknown Gemini variants (-low/-high for gemini-4): not seen locally, would risk unusable ids.
- Inventing OpenAI/Gemini prices: forbidden; left absent.
- Keeping budget thinking for 5.x: API rejects it.

## Risks

The image aliases `antigravity` to @google/gemini-cli; the gemini-4/3.8 ids come from the local agy config and are unverified against the shipped runtime (agy is off this round). Env profile overrides (ANTHROPIC_DEFAULT_*_MODEL) still take precedence over the shorthand map.

Saved `opus` settings now run Opus 5.5 (cheaper, newer). Mitigated by legacy aliases. Fable 5.2 is not in defaults.

## Verification

pytest for phase_config/thinking/usage/cache/gemini-id guard; frontend typecheck/lint; pod Agent SDK probe (done: opus/sonnet/haiku 5.5 answered).
