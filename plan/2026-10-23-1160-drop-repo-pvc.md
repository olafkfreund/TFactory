# Plan: drop the repo_pvc co-mount — packing is the only verify path (#1160 PR B)

Approved decisions (self-contained):

1. **Packing is the only verify path.** No workspace PVC anywhere. `nix_store_pvc`
   (`/nix`) stays.
2. **No toggle.** `TFACTORY_PACK_WORKSPACE` is read only to log once (WARNING,
   per process) that it is ignored. The gitops cleanup is a follow-up and goes
   in the PR body.
3. **Not fail-open.**
   - Dispatch pack `None`: `mark_stuck` with the reason prefix
     `verify workspace pack failed (failure_kind=environment)`. Then
     `status.json` gets `status: failed`, `phase: verify_workspace_pack_failed`,
     `verify: not_run`, `failure_kind: environment`, `reaped_reason`, plus a
     terminal notify. No Job is applied, and `VerifyWorkspacePackError` is
     raised. `_run_dispatch_blocking` treats that error as handled (`True`), so
     there is no in-pod fallback.
   - Lane pack or fetch failure: the output carries `__TF_LANE_NOT_COLLECTED__`,
     which classifies as `environment` and becomes `not_run`.
4. **Restore unchanged.** `tools/runners/artifact_store.py` gets no diff
   (vendored).

Branch: `refactor/1160-drop-repo-pvc`, base `dev`.
