# Plan: A Rust unit lane (cargo test)

Approved decisions (from spec/intent): framework `cargo-test` (language rust,
unit only, `.rs`, `Cargo.toml`, `tests/*.rs` top-level only, AC tokens
`cargo test`/`cargo build`, coverage skip); no hub or `languages/` descriptor
(`_LANG_ATTRS["rust"]` already provisions rustc+cargo); new module
`apps/backend/agents/nix_rust_lane.py` (nix_env.py untouched); `cargo test
--workspace --no-fail-fast`; exit 0 with zero tests -> 1, only-ignored -> 125;
per-target attribution via `Running tests/<name>.rs`, missing -> stability
ERROR; `mutation=None`; `network: restricted`; timeout 900 s. Base is origin/dev.
