# Plan: presign lane URLs with SigV4

Approved decisions: the 403 is botocore's legacy SigV2 presign (confirmed against
a local MinIO). Fix by forcing `signature_version="s3v4"` on the
`ArtifactStore` client. The lane script already sends
`x-amz-tagging: role=workspace` when the URL has no `x-amz-tagging=` query
param, which is the SigV4 shape, so script and presign agree with no script change.
Unpacked mode and plain `put_object` unchanged.

## Steps

1. apps/backend/tools/runners/artifact_store.py `_client` (~176-195): import
   `botocore.config.Config` lazily next to boto3, pass
   `config=Config(signature_version="s3v4")` to `boto3.client`, one-line why
   comment citing #1396 → verify by
   `cd apps/backend && PYTHONPATH=. python tools/runners/artifact_store.py` (self-test PASS).
   Traps: keep the boto3 import lazy (module must import without boto3).
2. tests/test_kube_sandbox.py (append): unit test for the SigV4 URL shape, and a
   MinIO round-trip test skip-marked on `TF_TEST_MINIO_ENDPOINT` → verify by
   `cd apps/backend && python -m pytest ../../tests/test_kube_sandbox.py -q`.
   Traps: never run the MinIO test in CI; use a throwaway local container and remove it.
