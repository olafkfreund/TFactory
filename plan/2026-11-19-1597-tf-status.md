# Plan: status endpoint reads status.json (#1597)

Approved decisions (spec): `GET /api/tasks/{id}/status` reads `<root>/workspaces/<project>/specs/<spec>/status.json` for `project:spec` ids; `phase` from the file, `message` from `failed_reason` else `reaped_reason`; `is_running = in_process or status in agents.liveness.ACTIVE_STATUSES`; a missing or malformed file falls back to today's answer; a readable file with an unknown status still supplies phase/message, and only `is_running` falls back to the in-process answer. A route dependency runs `require_task_access("viewer")` only for ids containing ":"; bare ids unchanged. `safe_component` on both parts. The MCP proxy needs no change.
